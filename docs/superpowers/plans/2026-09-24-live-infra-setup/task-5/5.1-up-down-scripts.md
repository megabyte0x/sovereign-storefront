# Subtask 5.1: `up.ts`, `down.ts` and npm scripts

Timebox: 60 min. Code and unit tests. You may run `up.ts` once at the end, since the stacks are already up and it should be a fast idempotent pass.

## Files

- Create `scripts/live-infra/up.ts`, `scripts/live-infra/down.ts` and `tests/unit/live-infra-updown.test.ts`.
- Modify `package.json` to add `"infra:up": "node --experimental-strip-types scripts/live-infra/up.ts"` and `"infra:down": "node --experimental-strip-types scripts/live-infra/down.ts"`.

## Behaviour

- `up.ts` runs `zcash-up.ts`, then `logos-up.ts`, then `waku-peers.ts`, as child processes with inherited env. Each child's stdout and stderr go to `.runtime/live/diag/up-<stage>-<ts>.log` (0600), and only the child's final status line is printed. It stops at the first nonzero stage and prints `<stage> FAILED (log: <path>)`. At the end it runs the doctor with `SSF_STRICT_LIVE=1`, prints only the row status lines, and exits with the doctor's code.
- `down.ts` runs `logos-down.ts`, then `zcash-down.ts`. It then checks for owned leftovers: `docker ps --filter name=tsz-ssf-live -q` must be empty; `pgrep -f "logos/node-(a|b)"` must be empty; `SCANNER_DIR/serve.pid`, if present, must name a dead PID; `pgrep -f "ths start --name ssf-live( |$)"` must be empty. Any leftover is printed by kind (not by secret value) and gives exit 1. It must never reference `ssf-task1`, `ssf-task3-live`, `default` or `p-happy`.
- Pure exported helpers for testing: `export const UP_ORDER = ['zcash', 'logos', 'waku'] as const`, `export const DOWN_ORDER = ['logos', 'zcash'] as const`, and `export function leftoverChecks(): { kind: string; argv: string[] }[]`.

## Tests first (RED, then GREEN)

- `UP_ORDER` and `DOWN_ORDER` equal the arrays above.
- `leftoverChecks()` argv, joined, contains `tsz-ssf-live` and `logos/node-`, and does not match `/ssf-task1|ssf-task3-live|p-happy|\bdefault\b/`.
- A stage-runner helper, if extracted, stops on the first nonzero exit. Use an injected fake runner and no real processes.

## Verify

`npx vitest run tests/unit/live-infra-updown.test.ts` passes, `npm run typecheck` is clean, and `npm run infra:up; echo exit=$?` exits 0 against the already-running stacks (print the row lines).
