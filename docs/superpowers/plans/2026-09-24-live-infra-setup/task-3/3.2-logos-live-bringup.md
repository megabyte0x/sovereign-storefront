# Subtask 3.2: First live `logos-up.ts` run

Timebox: 90 min. Precondition: Subtask 3.1 is done.

## Reference (original plan Task 3 Step 3, as implemented)

`logos-up.ts` does the following:
1. `ensurePrivateDir` for `logos/`, `logos/bin` and `logos/node-{a,b}`.
2. Copies the spike archive (or downloads release 0.2.3), verifies SHA-256 `f1ed1debcac20a9943ae2786021f574e439af42f853db0e753a365acb45eb3c3` before extracting, and chmods the AppImage to 0700.
3. Runs every call as `LOGOSCTL --config-dir <node> --json …` with `APPIMAGE_EXTRACT_AND_RUN=1`, each bounded to 60 s.
4. For each node: `daemon status`/`daemon start --detach`, `catalog refresh`, `package install storage_module --version 2.1.2 --root-hash 19b11b153748c30665608c5527776ba2be74f7764481a11d33f687098764b740 --yes` if it is missing, `module load storage_module`, then init from `storage-init.json` (0600) and `start`.
5. Polls `debug` until `result.value.id` is present, and requires the two peer IDs to differ.
6. Replication smoke: 41 random bytes, `uploadUrl` on A, `storageUploadDone` gives the CID, `connect` B→A with the explicit loopback multiaddr, `downloadToUrl` on B, `storageDownloadDone`, then the SHA-256 comparison. The plaintext temp files are deleted afterwards.
7. Merges the `LOGOSCTL`, `LOGOS_NODE_A`, `LOGOS_NODE_B` and `APPIMAGE_EXTRACT_AND_RUN=1` keys into `live.env`.

## Steps

1. **Socket-path pre-check (2 min).** Compute `Buffer.byteLength` for `<worktree>/.runtime/live/logos/node-a` plus the longest socket name logosctl creates. Find it after the first `daemon start` with `find .runtime/live/logos/node-a -type s`. If any socket path exceeds 100 bytes, **stop and return `blocked`**. The fix mirrors Subtask 2.1 (a short `LOGOS_DIR` in `paths.ts`), and the orchestrator must decide whether to add a Subtask 3.1b. Do not improvise it here.
2. Run:

       mkdir -p -m 700 .runtime/live/diag
       node --experimental-strip-types scripts/live-infra/logos-up.ts > .runtime/live/diag/3.2-logos-up.log 2>&1; echo exit=$?

   Expected: `exit=0`, and the last line is `logos-a=up logos-b=up replication=digest_match`.
3. On failure, read only `tail -n 30` of the diag log. Fix clear bugs in `logos-up.ts`, adding a unit test first where the logic is pure. Re-run. The script must be idempotent: a second run with both daemons up must also exit 0. After 2 failed fix attempts on the same error, return `blocked` with the error line and your hypothesis.
4. Idempotency: run it a second time, which must exit 0. Afterwards `pgrep -fc "logos/node-a"` must not have grown (compare with the count before).
5. Doctor: `npm run infra:doctor` → `logos-a PASS`, `logos-b PASS`, `logos-replication PASS`.
6. Confirm that no plaintext smoke file remains: `find .runtime/live/logos -name 'smoke-*'` should be empty or list only ciphertext/CID artifacts, with a justification for any that remain.
7. Leave both nodes running.
