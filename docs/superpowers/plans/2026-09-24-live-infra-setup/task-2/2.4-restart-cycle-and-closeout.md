# Subtask 2.4: Idempotency, teardown and restart cycle; Task 2 closeout

Timebox: 60 min. Precondition: Subtasks 2.1–2.3 are done (the stack is up, and the doctor shows zcash and scanner PASS).

## Steps

1. **Idempotent re-run while up.** Run `node --experimental-strip-types scripts/live-infra/zcash-up.ts > .runtime/live/diag/2.4-rerun.log 2>&1; echo exit=$?`. Expected: exit 0 through the `alreadyServing` path. No second `ths start` and no second `serve` should appear; verify with `pgrep -fc "ths start --name ssf-live"` = 1 and `pgrep -fc "sovereign-storefront-scanner serve"` counting only `SCANNER_DIR` configs = 1.
2. **Teardown.** Run `node --experimental-strip-types scripts/live-infra/zcash-down.ts; echo exit=$?`. Then all of these must be empty or zero:
   - `docker ps --filter name=tsz-ssf-live -q`
   - `pgrep -f "ths start --name ssf-live"`
   - `pgrep -f "sovereign-storefront-scanner serve"` restricted to `SCANNER_DIR`
   - Non-owned resources are still present: `pgrep -f "ths start --name ssf-task3-live"` is unchanged (record its PID before and after).
3. **Cold re-up.** Run `ZCASH_UP_TRACE=1 node --experimental-strip-types scripts/live-infra/zcash-up.ts > .runtime/live/diag/2.4-reup.log 2>&1; echo exit=$?` → 0. `ths` assigns new ports, so this also proves the `scanner.json` lightwalletd-endpoint re-provision path. Record whether re-provisioning happened (from the trace line `step4: (re)provisioning`).
4. Doctor: `SSF_STRICT_LIVE=1 npm run infra:doctor 2>&1 | grep -E '^(zcash|scanner) '` shows two PASS lines.
5. **Remove the obsolete old-path scanner dir** `<worktree>/.runtime/live/scanner/`. It holds a UFVK and wallet DB from before Subtask 2.1. First confirm no process has files open there (`lsof +D` on it, or `fuser -v`; if neither is available, check `pgrep` for its path). Then `rm -rf` exactly that path, and nothing else.
6. **Tracing decision.** Keep `ZCASH_UP_TRACE` (it is inert by default). Make sure no `trace()` call prints endpoint values that would count as secrets (ports are fine; keys and UFVKs are not). Run `grep -n "trace(" scripts/live-infra/zcash-up.ts` and inspect it.
7. **Step 5 of the original plan.** Run `npx vitest run tests/unit/wallet-scanner.test.ts`. It is deterministic, so it shows only that nothing regressed; it is not live evidence.
8. **DX backlog.** Append the `ths` observations confirmed in this task to `~/.hermes/skills/software-development/zakura-regtest/references/ths-dx-backlog.md` if they are still true and not already present: no detach flag (the foreground process is the environment anchor, and interrupting it deletes the env); `ths stop` does not end the `ths start` process; secrets printed on stdout at first start; `endpoints` has no network/TLS fields; random ports on every start.
9. **Regression gates:** `npm test && npm run typecheck && git diff --check`, each with its exit code. No commit.
10. Leave the stack **running** for Tasks 3–5.
