# 3.1 import and status commands  (parent Task 3)

Timebox 75 min. Owns: `tools/buyer-sender/src/main.rs`, `tools/buyer-sender/src/state.rs`.

Context: `state.rs` (StateDir, seed, open_wallet), `chain.rs` (connect, tip, sync, birthday_at, IMPORT_SYNC_DEADLINE, SYNC_BUDGET) exist — read their signatures only.

Implement:
- `trait ChainFactory` (or boxed async closure) that `main` constructs from `--lightwalletd` and hands to every command; commands call `factory.connect()` instead of `chain::connect` directly (README C1 seam).
- Helper `account_for_seed(db, seed) -> Result<AccountUuid, &'static str>`: `UnifiedSpendingKey::from_seed(&params, seed, zip32::AccountId::ZERO)`, `db.get_account_for_ufvk(&usk.to_unified_full_viewing_key())`; None → `"wallet account does not match the stored seed"`.
- `import --mnemonic-file F --birthday H`: open state; if a wallet exists and `get_account_ids()` is non-empty → exit 2 `"wallet already imported"`. `write_seed`, `open_wallet(Some(seed))`, connect, `birthday_at(H)`, `db.import_account_hd("ssf-buyer", &seed, AccountId::ZERO, &birthday, None)`, sync with `IMPORT_SYNC_DEADLINE`, tip → `{"ok":true,"birthday":H,"tip":T}`.
- `status`: open (seed required, else exit 2 `"wallet is not imported"`), account lookup, connect, sync (`SYNC_BUDGET`), `get_wallet_summary(ConfirmationsPolicy::default())`; None → exit 2 `"wallet is not synchronized"`; else JSON with `spendableZat`, `orchardZat`, `ironwoodZat` as decimal strings from the account balance (`spendable_value()`, `orchard_balance().spendable_value()`, `ironwood_balance().spendable_value()`), `"network":"test"`, `tip`.
- All errors map to fixed strings with exit 2 (nothing signed in these commands).

No tests. Do not run `import` against real funds or the real seed.

Verify:
- `npm run build:buyer-sender` exit 0.
- `ssf-buyer-sender --state-dir "$TMPDIR/ssf-buyer-probe" status` → `{"error":"wallet is not imported"}` exit 2.
- Optional network probe (read-only, no seed): none needed; the orchestrator runs real import only in Wave 8.
