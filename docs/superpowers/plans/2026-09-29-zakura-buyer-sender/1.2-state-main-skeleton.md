- `write_seed(mnemonic_file)`: refuse unless the file is owned by the current uid and mode 0600; parse `bip39::Mnemonic::parse_in(Language::English, …)`; store the normalized phrase in `seed.private` via `write_file_atomic`. Never echo it.

- `open_wallet(&self, seed: Option<&SecretVec<u8>>) -> Result<Db, &'static str>` mirroring `scan.rs::open_wallet` but with `ScannerParams::test_network()`; then `init_wallet_db(&mut db, seed)`. `type Db = WalletDb<Connection, ScannerParams, SystemClock, UnwrapErr<SysRng>>`.

- `Attempt { attempt_id, txid, raw_hex, target_height: u32, expiry_height: u32, amount_zat: u64, created_at: u64 }` (serde, camel or snake — pick snake, file-internal).
