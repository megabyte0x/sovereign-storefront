# 1.1 Manifest and lockfile  (parent Task 1.1–1.3)

Timebox 45 min. Owns: `tools/buyer-sender/Cargo.toml`, `tools/buyer-sender/Cargo.lock`, and visibility keywords only in `services/scanner/src/*.rs`.

Steps:
1. Create `tools/buyer-sender/Cargo.toml`: `[package] name = "ssf-buyer-sender"`, `version = "0.1.0"`, `edition = "2024"`, `rust-version = "1.91"`, `publish = false`; `[[bin]] name = "ssf-buyer-sender" path = "src/main.rs"`.
2. Copy these dependency lines verbatim (same renames, pins, features) from `services/scanner/Cargo.toml` `[dependencies]` (lines ~9–31): `zcash_client_backend`, `zcash_client_sqlite`, `zakura_pczt`, `zcash_keys`, `zcash_primitives`, `zcash_protocol`, `zcash_address`, `zip32`, `zip321`, `tokio`, `tonic`, `prost`, `rusqlite`, `serde`, `serde_json`, `hex`, `sha2`, `getrandom`, `rand_core`, `nix` (already has `fs`). Add any other scanner dep that the pattern in `scan.rs` lines 145–190 needs to open a `WalletDb` (e.g. the `SystemClock`/`SysRng` providers) — grep the scanner's `use` lines for them.
3. Add:
   ```toml
   sovereign-storefront-scanner = { path = "../../services/scanner" }
   zcash_proofs = { package = "zakura-proofs", version = "=1.2.0", default-features = false, features = ["bundled-prover", "multicore"] }
   orchard = { package = "zakura-orchard", version = "=1.2.0", default-features = false }
   bip39 = { version = "=2.2.2", default-features = false, features = ["std"] }
   secrecy = "=0.8.0"
   zeroize = "=1.9.0"
   ```
   Check the scanner lib's package/lib name in `services/scanner/Cargo.toml` and use it. `bip39` is not in the scanner lock (expected; it is a leaf).
4. Add a placeholder `tools/buyer-sender/src/main.rs` with `fn main() {}` only so cargo can resolve (1.2 replaces it).
5. `cp services/scanner/Cargo.lock tools/buyer-sender/Cargo.lock`, then `cargo check --manifest-path tools/buyer-sender/Cargo.toml` once (no `--locked`). Never `cargo update`/`generate-lockfile`.
6. Parent 1.3: all scanner items are expected to be `pub` already (README C5). Only if a compile error names one, change its visibility keyword; nothing else in the scanner.
7. Ensure `tools/buyer-sender/target/` is ignored (`git check-ignore -v tools/buyer-sender/target/x`); if not, report a deviation for `.gitignore` (do not edit it).

Verify:
- `cargo check --locked --manifest-path tools/buyer-sender/Cargo.toml` exit 0.
- `cargo tree --manifest-path tools/buyer-sender/Cargo.toml -d -e normal | grep -E '^(zakura|zcash|orchard|sapling|halo2)'` prints nothing.
- `diff <(grep -A1 '^name = "zakura' services/scanner/Cargo.lock) <(grep -A1 '^name = "zakura' tools/buyer-sender/Cargo.lock)` shows only additions (no version changes).

Blocked-exit: a duplicate crypto family or a changed shared version → stop, report the `cargo tree -d` lines.
