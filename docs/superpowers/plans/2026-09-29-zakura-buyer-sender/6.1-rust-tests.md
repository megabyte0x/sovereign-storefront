# 6.1 Rust unit tests  (parent Task 6.1)

Timebox 120 min. Owns: `#[cfg(test)] mod tests` blocks appended to `tools/buyer-sender/src/{state,chain,pay,main}.rs`. Do not change non-test code; if a seam is missing, report a deviation with the exact signature needed and stop that case (blocked only if >2 cases are affected).

Cases:
- Invoice (`pay::validate_invoice`): fixture `utest1` from `UnifiedSpendingKey::from_seed(&ScannerParams::test_network(), &[7u8; 32], AccountId::ZERO)` → default address → ZIP-321 URI. Accept valid. Reject: mainnet `u1…` (derive with MAIN_NETWORK), two payments, amount 0, amount 1_000_001, attempt-id mismatch, trailing-newline file (C2).
- Status (`chain::decode_status`): NotFound → not_found; NotFound + tip>expiry → expired; NotFound + tip==expiry → not_found; Unavailable and DeadlineExceeded → Err, never not_found; height 0 → mempool; `u64::MAX` → forked; n → mined(n); payload with a different txid → malformed; trailing bytes → malformed. Build a real tx payload from `zcash_primitives` test helpers if available, else feature-gate those two cases and report.
- Broadcast (`chain::map_broadcast`): 0 → accepted; nonzero with message "secret-ish" → rejected and `as_str()` output does not contain the message; Err → unknown.
- Attempt file: create-new refuses an existing file; mode 0600; `read_attempt` rejects uppercase/short/non-hex ids.
- Pay guard: existing attempt → exit 4 with a `ChainFactory` that panics on use.
- `parse_expiry_delta`: None→20, 9/41 rejected, 10/40 accepted, non-numeric rejected.
- Output hygiene: serialize every output shape from fixtures; assert no `utest1`, `uviewtest`, `zcash:` or 65+ hex run.

Use `tempfile`-free temp dirs under `std::env::temp_dir()` (TMPDIR points at the Hermes scratch dir); remove them.

Verify:
- `cargo test --locked --manifest-path tools/buyer-sender/Cargo.toml` all pass (log to diag, report the count).
- `cargo clippy --locked --manifest-path tools/buyer-sender/Cargo.toml -- -D warnings` exit 0.
